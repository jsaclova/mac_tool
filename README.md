# 🍏 맥 유틸리티 종합 자동화 툴킷 (mac_tool)

맥(macOS) 환경에서 터미널 기반 시스템 분석 및 프로세스 제어, 터미널 이력 완전 소멸을 통합 제어하는 패키지입니다.

---

## 🚀 원클릭 초고속 설치 및 상시 최신 업데이트 가이드

새로운 PC에 처음 설치할 때나, 추후 코드가 변경되었을 때 **아래 한 줄만 복사해서 실행**하면 깃허브 저장소로부터 패키지를 내려받아 터미널 환경을 언제든지 최신 상태로 원스톱 동기화 업데이트합니다.

```bash
curl -sSL https://github.com -o /tmp/mac_install && chmod +x /tmp/mac_install && /tmp/mac_install && rm -f /tmp/mac_install
```

> ⚠️ **설치 후 최초 1회 필수 완료 명령어**: `source ~/.zshrc`

---

## 🛠 핵심 명령어 구성 안내

| 명령어 | 주요 기능 | 비고 |
| :--- | :--- | :--- |
| **`netclean`** | 터미널 입력 이력 **영구 삭제** | 활성화된 메모리 이력 휘발(`history -c`) 및 물리 로그 파일까지 흔적 없이 완전히 증발 (0번 즉시 취소 탑재) |
| **`mac_install`** | 툴킷 **자가 복제 및 업데이트** | 터미널에 입력하면 언제든지 깃허브로부터 최신 변경 사항 코드를 실시간 원클릭 업데이트 교체 |
| **`macman`** | 터미널 통합 **매뉴얼 뷰어** | 방향키로 맥 유틸리티 도구 가이드를 정독하는 매뉴얼 구동 (`q`를 누르면 복귀) |
